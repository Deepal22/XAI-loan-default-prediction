## 🚀 Project Overview

An end-to-end Explainable AI (XAI) based loan default prediction system built using XGBoost and SHAP to provide transparent and interpretable credit risk analysis.

This system predicts whether a customer is likely to default on a loan while also explaining *why* the prediction was made using SHAP Explainability.

The project demonstrates:
- Machine Learning pipeline development
- Explainable AI integration
- Real-time prediction system
- Interactive dashboard deployment
- Production-ready ML workflow

# 🧠 Explainable AI (XAI)

Traditional machine learning models behave like black boxes.

This project integrates SHAP (SHapley Additive exPlanations) to make predictions:
- Transparent
- Interpretable
- Trustworthy

The dashboard explains:
- Why a customer may default
- Which features influenced prediction
- Positive & negative contributing factors

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Deepal22/XAI-loan-default-prediction.git
cd XAI-loan-default-prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
